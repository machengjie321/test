# Rebuttal Figures Bundle

This folder collects the figure assets prepared for rebuttal upload to an anonymous GitHub repository.

## Structure

- `figures/`: image assets to upload

## Suggested Upload Workflow

1. Create a new anonymous GitHub repository.
2. Upload the contents of this folder, preserving the `figures/` directory.
3. Use raw GitHub links in your rebuttal, e.g.

```text
https://raw.githubusercontent.com/<anonymous-user>/<anonymous-repo>/<branch>/figures/<file-name>.png
```
